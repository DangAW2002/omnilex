## Easy explanation
Core Web Vitals are like a doctor’s checkup report for a website: they measure how quickly the heart starts beating (loading), how fast it reacts to a reflex tap (responsiveness), and whether things wobble around unexpectedly (stability).

## Details
Formulated by Google, Core Web Vitals identify three foundational facets of user experience measured through real-user monitoring (RUM): Largest Contentful Paint (LCP) measures perceived loading speed, Interaction to Next Paint (INP) measures overall interactive responsiveness to user clicks and taps, and Cumulative Layout Shift (CLS) measures visual stability against unexpected content shifting. Scores directly influence search engine ranking algorithms.

## Technical definition
A standardized triad of field-measured user experience metrics quantifying visual loading latency, interaction delay, and structural layout shift.

## Examples
A news site improves its LCP score from 4.2 seconds down to 1.8 seconds by optimizing image formats, achieving a "Good" rating in search console diagnostics.
