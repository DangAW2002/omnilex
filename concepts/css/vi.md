## Giải thích dễ hiểu
Nếu HTML là phần khung xây thô thì CSS là lớp hoàn thiện nội thất: màu sơn tường, gạch lát sàn, rèm cửa và ánh sáng trang trí.

## Chi tiết
CSS áp dụng kiểu dáng thông qua các bộ chọn (selectors) liên kết với danh sách thuộc tính và giá trị. Thuật ngữ "cascading" (xếp tầng) thể hiện quy tắc giải quyết xung đột khi nhiều quy tắc cùng trỏ vào một phần tử, dựa trên nguồn gốc, độ cụ thể và thứ tự khai báo. CSS hiện đại cung cấp các mô hình dựng hình mạnh mẽ như Flexbox và Grid, biến CSS (custom properties) và truy vấn phương tiện (media queries).

## Định nghĩa chuyên ngành
Ngôn ngữ định dạng dạng khai báo xác định cách các phần tử trong cây DOM được hiển thị trên màn hình, bản in hoặc các thiết bị đầu ra khác.

## Ví dụ
Đoạn mã .card { padding: 16px; border: 1px solid #ddd; border-radius: 8px; } giúp khối nội dung có khoảng cách đệm và đường viền bo tròn thẩm mỹ.
