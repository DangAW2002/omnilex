## Easy explanation
HTML is the structural skeleton of a house: it establishes where the walls, doors, windows, and staircases go before painting or wiring begins.

## Details
HTML uses a hierarchy of elements defined by opening and closing tags enclosed in angle brackets. Elements can encapsulate text, embed images and multimedia, declare hyperlinks, and organize tabular or form data. Attributes provide metadata or configuration for elements. Modern HTML5 prioritizes semantic tags such as <article>, <section>, <nav>, and <header>, which allow assistive tools and search engines to interpret document hierarchy effectively.

## Technical definition
An SGML-derived markup language defining elements, attributes, and syntax rules parsed into the Document Object Model tree by rendering engines.

## Examples
A document containing <main><h1>Product List</h1><p>Welcome to our store.</p></main> establishes heading and paragraph hierarchy rendered directly by the browser.
