## Easy explanation
Instead of writing an exhaustive checklist of rules describing every possible cat photo, you feed a computer ten thousand labeled pictures and let it discover the distinguishing visual features on its own.

## Details
Machine learning shifts software engineering from hardcoded conditional heuristics to probabilistic inductive inference. Practitioners supply historical data, engineer features or representations, select an objective loss metric, and execute optimization routines. The field branches into supervised learning with known target labels, unsupervised clustering discovering hidden structures, and reinforcement learning guided by environmental reward signals.

## Technical definition
Computational discipline dedicated to algorithms that optimize performance parameters on specified tasks through automated inductive inference across empirical observations.

## Examples
A spam filter adjusting internal classification thresholds dynamically as users flag novel phishing emails, rather than requiring engineers to hardcode new keyword filters.
