## Easy explanation
A prompt is like the brief you hand a freelance writer: the clearer the task, the background and the expected format, the closer the first draft is to what you wanted.

## Details
A prompt can be one question or a long document with instructions, examples and data. In chat apps it combines a system part set by the developer with the turns typed by the user. Wording, order and examples all change the output, which is why writing prompts has become a skill of its own, prompt engineering.

## Technical definition
The input handed to a large language model for one request, which shapes what the model generates in reply.

## Examples
"Summarise this contract in five bullet points for someone who is not a lawyer" is a prompt that names a task, an audience and an output format.
