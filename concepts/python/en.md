## Details
Created by Guido van Rossum in 1991, Python emphasizes readability by using whitespace indentation to delimit code blocks rather than curly braces or keywords. It features dynamic typing, automatic garbage collection, and a multi-paradigm architecture accommodating object-oriented, procedural, and functional programming patterns. While its standard reference interpreter (CPython) compiles code to bytecode interpreted within a runtime, Python bridges high performance by binding natively to optimized C, C++, and Fortran libraries, underpinning the modern artificial intelligence, scientific computing, and web service ecosystems.

## Technical definition
A dynamically typed, garbage-collected, interpreted high-level programming language supporting multiple programming paradigms through a modular design and an extensive standard library.
