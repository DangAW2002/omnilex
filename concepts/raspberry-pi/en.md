## Easy explanation
Think of a pocket-sized computer that plugs into an ordinary television screen and keyboard, giving makers, students, and engineers a cheap playground to write code, build home media servers, or command robot motors.

## Details
Originating as an educational computer created by the Raspberry Pi Foundation, the device series has grown into a dominant hardware building block across academic, prototyping, and light industrial landscapes. Powered by Broadcom ARM application processors, typical boards include gigabit Ethernet, multiple USB ports, HDMI display outputs, Wi-Fi, Bluetooth, and a standardized 40-pin GPIO array. Developers boot the computer from microSD cards or NVMe solid-state storage into a specialized Debian derivative called Raspberry Pi OS.

## Technical definition
A standardized family of ARM-architecture single-board computing systems featuring broad peripheral connectivity, Linux operating system execution capabilities, and exposed general-purpose digital input-output arrays.

## Examples
A maker connects an environmental sensor kit to the GPIO pins of a Raspberry Pi 5 to monitor greenhouse temperature and stream automated metric dashboards over local Wi-Fi.
