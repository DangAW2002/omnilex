## Easy explanation
Think of an air traffic control center with radar screens tracking hundreds of airplanes at once: instead of watching every single cockpit gauge individually, the central tower aggregates radar signals and altitude logs to detect dangerous flight path conflicts before accidents happen.

## Details
Security Information and Event Management (SIEM) merges Security Event Management (real-time analysis of network traffic and device telemetry) with Security Information Management (long-term log retention and compliance reporting). SIEM collectors ingest log data from firewalls, servers, endpoints, identity providers, and cloud services. The normalization engine translates disparate formats into standard event schemas. Advanced correlation algorithms and User and Entity Behavior Analytics (UEBA) cross-reference multiple seemingly benign events—such as an unusual login time followed by large file downloads—to generate contextual security alerts for analysts.

## Technical definition
A centralized security architecture and operational toolset providing real-time analysis of security alerts generated by applications and network hardware alongside comprehensive log retention for compliance and forensics.

## Examples
An enterprise SIEM aggregates syslog streams from 500 virtual machines and triggers a critical incident alert when an employee account authenticates from two different continents within twenty minutes.
