# English Style Guide for Termbridge

This style guide establishes editorial standards for English-language concept documentation in Termbridge.

## 1. Audience & Voice

- **Target Audience:** Cross-disciplinary practitioners, students, and people crafting precision AI prompts.
- **Voice:** Direct, lucid, grounded, and concise. Avoid circular jargon definitions.

## 2. Frontmatter Standards

### `label`
- Standard title case or widely recognized acronym (e.g. `Compound Interest`, `ROI`).
- If an identical label exists in another concept, append a clear `qualifier` such as `(AI)` or `(Authentication)`.

### `plain_descriptions`
- Supply colloquial phrasing used by non-experts during reverse lookups.
- Write natural descriptions (e.g. "interest on interest", "money snowballing because earnings get added back").

### `summary`
- A single crisp sentence explaining the core purpose under 30 words.

## 3. Body Section Requirements

1. **## Easy explanation:** An intuitive real-world analogy.
2. **## Details:** The operational mechanics, formulas, or runtime behaviors.
3. **## Technical definition:** Formal definition conforming to recognized domain standards.
4. **## Examples:** Concrete practical or numerical scenarios.
