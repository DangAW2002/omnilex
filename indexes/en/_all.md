# Termbridge Master Index (en)

- [**Chain-of-thought prompting**](../../concepts/chain-of-thought/en.md) [it/ai-ml/llm-agents]: *asking the AI to think step by step, making the AI show its working before the answer* — A prompting technique that asks a model to reason through intermediate steps before it gives the final answer.
- [**Compound Interest**](../../concepts/compound-interest/en.md) [finance/personal-finance/saving, finance/investing/portfolio-risk]: *interest on interest, money snowballing because earnings get added back to the pile* — Interest calculated on both the initial principal and the accumulated interest from previous periods.
- [**Context window**](../../concepts/context-window/en.md) [it/ai-ml/llm-agents]: *how much text the AI can keep in mind at once, the AI’s working memory limit* — The maximum amount of text, counted in tokens, that a model considers in one request, covering the prompt, the conversation so far and its reply.
- [**Cookie**](../../concepts/cookie/en.md) [it/web/frontend, media/digital-marketing/paid-ads]: *small browser file websites save to remember your login, web tracker banner you click accept on* — A small piece of data stored on the user's browser by websites to retain state and track browsing activity.
- [**Embedding**](../../concepts/embedding/en.md) [it/ai-ml/nlp]: *turning words into a list of numbers so a computer can compare meanings, numbers that place similar ideas close together* — A list of numbers learned by a model to represent an item such as a word or a document, so that similar items end up close together.
- [**Few-shot prompting**](../../concepts/few-shot-prompting/en.md) [it/ai-ml/llm-agents]: *showing the AI a few examples before asking, teaching by examples inside the question* — A prompting technique that includes a few worked examples of the task so the model follows the same pattern.
- [**Fine-tuning**](../../concepts/fine-tuning/en.md) [it/ai-ml/mlops]: *training an existing AI a bit more on your own examples, teaching a ready-made model a specialised job* — Further training of a pre-trained model on a smaller task-specific dataset so it performs better on that task or style.
- [**Function calling**](../../concepts/function-calling/en.md) [it/ai-ml/llm-agents]: *letting the AI press buttons in other apps, the AI asking your code to fetch data or run an action* — A model capability to reply with a structured request to call a tool the developer defined; the app runs it and returns the result.
- [**Guardrail (AI)**](../../concepts/guardrail/en.md) [it/ai-ml/ai-safety-governance]: *safety filters around a chatbot, rules that block harmful or off-topic AI answers* — A control around a model’s inputs or outputs that detects and blocks unsafe, off-policy or off-topic content.
- [**Hallucination (AI)**](../../concepts/hallucination/en.md) [it/ai-ml/llm-agents]: *when the AI confidently makes things up, a made-up fact or fake citation from a chatbot* — Output from a generative model that sounds plausible but is false or unsupported, presented as if it were fact.
- [**Interest Rate**](../../concepts/interest-rate/en.md) [finance/economics/interest-rates-monetary-policy, finance/banking/deposits]: *percentage fee charged for borrowing money, percentage reward earned on savings per year* — The proportion of an amount loaned which a lender charges as interest to the borrower, typically expressed as an annual percentage.
- [**Jailbreak (AI)**](../../concepts/jailbreak/en.md) [it/ai-ml/ai-safety-governance]: *tricking a chatbot into breaking its own safety rules, prompts that make the AI say what it should refuse* — A prompt designed to make a model ignore its safety guidelines and produce content it is meant to refuse.
- [**Large Language Model**](../../concepts/llm/en.md) [it/ai-ml/llm-agents]: *an AI that writes text by guessing the next word, the kind of chatbot brain behind ChatGPT, Gemini or Claude* — A very large neural network trained on huge amounts of text that reads and writes language by predicting the next token.
- [**Low-Rank Adaptation**](../../concepts/lora/en.md) [it/ai-ml/mlops]: *a cheap way to fine-tune by training only a small add-on, small adapter files that teach a big model a new skill* — A parameter-efficient fine-tuning method that freezes the original weights and trains small low-rank matrices that represent the weight update.
- [**Margin (Trading)**](../../concepts/margin/en.md) [finance/investing/stocks]: *using assets in a brokerage account as collateral to borrow money for securities, the equity required in an account when buying securities with borrowed money* — Assets in a brokerage account support a loan used to buy securities.
- [**Model Context Protocol**](../../concepts/mcp/en.md) [it/ai-ml/llm-agents]: *a standard plug that lets AI apps connect to tools and data, one common way for chatbots to talk to other software* — An open protocol that standardises how AI applications connect to external tools, data sources and workflows through MCP servers.
- [**Principal**](../../concepts/principal/en.md) [finance/personal-finance/saving, finance/banking/lending]: *original sum of money borrowed or invested, money before any interest gets calculated* — The original sum of money lent, invested, or borrowed before interest accrues.
- [**Profit margin (Accounting)**](../../concepts/profit-margin/en.md) [finance/corporate-finance/financial-statements]: *how much profit a company keeps from each dollar of revenue, the percentage of sales that remains as profit* — A percentage comparing a specified measure of profit with the corresponding revenue.
- [**Prompt**](../../concepts/prompt/en.md) [it/ai-ml/llm-agents]: *what you type to tell the AI what to do, the question or instructions you give a chatbot* — The text, and sometimes images or files, given to a language model as input to steer what it produces.
- [**Prompt caching**](../../concepts/prompt-caching/en.md) [it/ai-ml/llm-agents]: *saving the unchanging start of a prompt so later calls are cheaper and faster, not paying full price to resend the same long instructions* — A provider feature that keeps the processed beginning of a prompt so later requests starting the same way cost less and answer faster.
- [**Prompt injection**](../../concepts/prompt-injection/en.md) [it/ai-ml/ai-safety-governance]: *tricking an AI with hidden instructions in text it reads, a web page or file that secretly tells the chatbot to misbehave* — An attack in which crafted input, typed by a user or hidden in content the model reads, overrides the application’s intended instructions.
- [**Retrieval-Augmented Generation**](../../concepts/rag/en.md) [it/ai-ml/llm-agents]: *letting the AI look things up in your documents before it answers, a chatbot that answers from a company’s own files* — A technique that retrieves relevant documents when a question arrives and adds them to the prompt so the model answers from them.
- [**Return on Investment**](../../concepts/roi/en.md) [finance/investing/valuation, media/digital-marketing/metrics-analytics]: *how much money you make back compared to what you spent, performance metric measuring profitability of an expense* — A performance metric used to evaluate the efficiency or profitability of an investment relative to its cost.
- [**Simple Interest**](../../concepts/simple-interest/en.md) [finance/personal-finance/saving, finance/banking/lending]: *interest calculated solely on the initial deposit, fixed interest payment that never compounds* — Interest calculated exclusively on the original principal amount for the entirety of the loan or deposit period.
- [**Structured output**](../../concepts/structured-output/en.md) [it/ai-ml/llm-agents]: *making the AI reply in an exact data format, getting JSON back instead of free text* — Model output constrained to follow a given format, usually a JSON schema, so that software can read it reliably.
- [**System prompt**](../../concepts/system-prompt/en.md) [it/ai-ml/llm-agents]: *hidden instructions an app gives the AI before you start chatting, the rules that set an assistant’s role and tone* — Instructions placed before the conversation that set the model’s role, rules and style for every later message.
- [**Token (Authentication)**](../../concepts/token-auth/en.md) [it/security/authentication, it/web/api]: *digital access pass sent with web requests, encoded string proving you are logged in* — A cryptographically signed string presented to servers to prove identity and authorization permissions.
- [**Token (Cryptocurrency)**](../../concepts/token-crypto/en.md) [finance/investing/digital-assets]: *digital asset issued on an existing blockchain, utility or governance coin within a decentralized app* — A digital unit of value issued on top of an existing smart contract blockchain platform.
- [**Token (AI)**](../../concepts/token-llm/en.md) [it/ai-ml/llm-agents]: *unit AI uses to count text chunks, why AI charges per prompt length* — Small chunk of text, typically subword units, processed by large language models.
- [**Tokenizer**](../../concepts/tokenizer/en.md) [it/ai-ml/nlp]: *the part that chops text into pieces the AI can read, what decides how many tokens a sentence costs* — The component that splits input such as text into tokens from a fixed vocabulary and turns them into numeric ids for the model.
- [**Vector database**](../../concepts/vector-database/en.md) [it/ai-ml/nlp]: *a database that finds things by similar meaning, storage that searches by how close lists of numbers are* — A database built to store embedding vectors and quickly return the ones most similar to a query vector.
