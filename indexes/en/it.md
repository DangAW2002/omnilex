# Termbridge Index: Information Technology (en)

- [**Agent (AI)**](../../concepts/ai-agent/en.md): *an AI system that plans steps and uses tools to achieve goals independently; a software assistant that observes its environment, takes actions, and completes tasks* — An autonomous AI system that reasons over objectives, breaks goals into sequential steps, and interacts with tools and environments to complete tasks.
- [**Benchmark (AI)**](../../concepts/ai-benchmark/en.md): *standardized test suites used to measure AI model accuracy and hardware speed; common evaluation exams allowing different AI systems to be fairly compared* — A standardized test suite and measurement protocol used to evaluate and compare the accuracy, throughput, latency, or energy efficiency of models and hardware.
- [**Application Programming Interface (API)**](../../concepts/api/en.md): *a defined bridge that allows two software systems to talk to each other; a digital waiter taking requests from one application to another* — A set of defined rules, protocols, and endpoints enabling different software applications to communicate and exchange data.
- [**Application Programming Interface (API)**](../../concepts/api/en.md): *a defined bridge that allows two software systems to talk to each other; a digital waiter taking requests from one application to another* — A set of defined rules, protocols, and endpoints enabling different software applications to communicate and exchange data.
- [**Endpoint (API)**](../../concepts/api-endpoint/en.md): *the specific web address where an app sends requests to get certain information; a digital front door where external software asks a server to do something* — A dedicated network address and URL path exposed by an API where clients access a specific service or resource.
- [**Attention mechanism**](../../concepts/attention-mechanism/en.md): *an AI technique that weighs which input words matter most at each step; the computational method letting models focus dynamically on relevant context* — A mathematical algorithm allowing neural models to calculate dynamic relevance weights between all tokens within an input sequence.
- [**Autoscaling**](../../concepts/autoscaling/en.md): *automatically adding more servers when traffic spikes and removing them when things quiet down to save money; the system capability that expands or shrinks computing power based on real-time demand* — A cloud mechanism that automatically adjusts the number of active computing resources up or down based on real-time demand metrics.
- [**Batch size**](../../concepts/batch-size/en.md): *the number of training examples processed together in one forward and backward step; how many data samples an AI looks at before updating its internal weights* — The number of training samples processed simultaneously in a single iteration before the model parameters are updated.
- [**Blue-green deployment**](../../concepts/blue-green-deployment/en.md): *running two identical environments side by side and switching user traffic instantly to the new one; a release technique that eliminates downtime by preparing updates in a cloned backup environment* — A deployment strategy that provisions two identical production environments (Blue and Green), shifting all traffic from the active to the idle environment upon validation.
- [**Breaking change**](../../concepts/breaking-change/en.md): *a modification in software or an API that breaks existing programs depending on it; an update that requires downstream developers to rewrite parts of their code to keep working* — A modification in a software interface, dependency, or system component that breaks backward compatibility and necessitates code adjustments in dependent systems.
- [**Cache (Software)**](../../concepts/cache/en.md): *a fast temporary storage area saving frequent answers so the computer skips slow re-calculations; keeping copies of popular web pages in memory so users don't wait for slow database queries* — A high-speed data storage layer that stores a subset of transient data so future requests are served faster than accessing primary storage.
- [**Canary release**](../../concepts/canary-release/en.md): *testing a new software version on a tiny percentage of real users before releasing it to everyone; a gradual rollout technique that exposes early bugs safely without risking the entire user base* — A deployment technique that exposes a new software release to a small fraction of production traffic to validate behavior before broader rollout.
- [**Content Delivery Network (CDN)**](../../concepts/cdn/en.md): *a worldwide network of caching servers that delivers web pages and images quickly from locations near the user; a distributed cache that speeds up websites by serving files from nearby edge servers* — A geographically distributed network of proxy servers that caches and delivers web content to users with low latency and high availability.
- [**Chain-of-thought prompting**](../../concepts/chain-of-thought/en.md): *asking the AI to think step by step; making the AI show its working before the answer* — A prompting technique that asks a model to reason through intermediate steps before it gives the final answer.
- [**CI/CD**](../../concepts/ci-cd/en.md): *automatically building, testing, and shipping code changes whenever engineers push work; the automated pipeline that moves software from development to live production servers* — A modern engineering methodology uniting frequent source integration with automated regression testing and reliable application deployment.
- [**Pipeline (CI/CD)**](../../concepts/ci-pipeline/en.md): *the step-by-step automated workflow that builds, tests, and packages code changes; the scripted sequence that takes software from a commit to a deployable artifact* — A defined sequential series of automated execution steps that compiles, tests, and packages application updates.
- [**Code review**](../../concepts/code-review/en.md): *having teammate developers examine your code changes before merging; a peer inspection of source code to catch bugs and uphold standards* — A collaborative peer-review practice where software engineers systematically examine proposed code changes to identify defects, enforce architectural standards, and share knowledge.
- [**Image (Container)**](../../concepts/container-image/en.md): *the static template or blueprint used to create and run containers; a frozen snapshot of software files, system libraries, and startup commands* — An immutable, read-only package containing application binaries, libraries, configuration files, and metadata required to launch a container.
- [**Context engineering**](../../concepts/context-engineering/en.md): *the practice of carefully designing and managing everything fed into an AI's context window; organizing tokens, instructions, tools, and history to maximize AI accuracy and reduce cost* — The disciplined practice of curating, structuring, compressing, and caching the information loaded into a model's context window to optimize performance and efficiency.
- [**Context window**](../../concepts/context-window/en.md): *how much text the AI can keep in mind at once; the AI’s working memory limit* — The maximum amount of text, counted in tokens, that a model considers in one request, covering the prompt, the conversation so far and its reply.
- [**Cookie**](../../concepts/cookie/en.md): *small browser file websites save to remember your login; web tracker banner you click accept on* — A small piece of data stored on the user's browser by websites to retain state and track browsing activity.
- [**Cross-Origin Resource Sharing (CORS)**](../../concepts/cors/en.md): *a browser security check deciding if one website can fetch data from another domain; the rules preventing malicious websites from secretly querying your banking API* — A browser security protocol using special HTTP headers that lets an API grant specific foreign websites permission to fetch its content.
- [**Cross-Origin Resource Sharing (CORS)**](../../concepts/cors/en.md): *a browser security check deciding if one website can fetch data from another domain; the rules preventing malicious websites from secretly querying your banking API* — A browser security protocol using special HTTP headers that lets an API grant specific foreign websites permission to fetch its content.
- [**Cross-site request forgery (CSRF)**](../../concepts/csrf/en.md): *an attack that tricks your browser into making unwanted money transfers on sites where you are logged in; clicking a trap link on an external page that secretly submits a form to change your account email* — An attack that tricks an authenticated web browser into sending unauthorized commands to a vulnerable web application without the user’s consent.
- [**Common Vulnerabilities and Exposures (CVE)**](../../concepts/cve/en.md): *the standardized global dictionary of publicly recognized cybersecurity flaws and software bugs; an official tracking code like CVE-2021-44228 identifying a specific security flaw* — A publicly available list of standardized identifiers for cybersecurity vulnerabilities and exposures.
- [**Data lake**](../../concepts/data-lake/en.md): *a huge digital reservoir where companies store raw data in any format until needed; a flexible storage pool holding audio, text, images, and logs without forcing strict table structures* — A scalable storage repository designed to retain massive volumes of raw multi-format information without requiring an upfront database schema.
- [**Data pipeline**](../../concepts/data-pipeline/en.md): *an automated series of steps moving information from where it is created to where it is used; software plumbing that pumps live data from user clicks into analytics systems* — An automated sequence of processes that ingests, processes, and transfers raw data from source systems to destination storage.
- [**Data warehouse**](../../concepts/data-warehouse/en.md): *a central database designed specifically for business analysis and fast executive reporting; a giant organized filing room where companies store cleaned historical business records* — A centralized, relational repository that aggregates structured historical data from across an organization to power business intelligence and reporting.
- [**Index (Database)**](../../concepts/database-index/en.md): *a sorted lookup helper that lets the database find specific rows in milliseconds instead of scanning the whole disk; an alphabetical index at the back of a book pointing directly to table rows* — A specialized data structure associated with a database table that accelerates record retrieval at the expense of extra storage and slower writes.
- [**Migration (Database)**](../../concepts/database-migration/en.md): *a version-controlled script that safely updates database table layouts as software evolves; a step-by-step code file for adding new columns or tables to live databases* — A version-controlled set of programmatic scripts that safely alter database schemas over time without losing existing data.
- [**Replication (Database)**](../../concepts/database-replication/en.md): *copying database records automatically to backup servers so the system survives hardware failures; syncing data across multiple database copies so heavy user reads don't slow down writes* — The continuous electronic copying of data from one database server to one or more replica servers to ensure high availability and read scalability.
- [**Schema (Database)**](../../concepts/database-schema/en.md): *the overall architectural blueprint defining the tables, columns, and rules in a database; the formal structural layout describing what kinds of data a database is allowed to hold* — The formal structural blueprint of a database that defines tables, fields, data types, relationships, and integrity constraints.
- [**Transaction (Database)**](../../concepts/database-transaction/en.md): *an all-or-nothing group of database operations that either completely succeeds or leaves data untouched; a safe execution wrapper ensuring money transfers debit one account and credit another atomically* — A sequence of database operations executed as a single, atomic unit of work satisfying ACID properties.
- [**Dataset**](../../concepts/dataset/en.md): *a structured collection of examples used to teach or test AI; the organized data gathered together for machine learning experiments* — A structured collection of data records, features, and targets partitioned to train, validate, and benchmark algorithms.
- [**Deep learning**](../../concepts/deep-learning/en.md): *machine learning powered by deep neural networks with many hidden layers; advanced AI techniques that automatically learn rich representations from raw data* — A specialized subset of machine learning utilizing multi-layered neural networks to extract hierarchical feature representations directly from complex data.
- [**Deprecation (Software)**](../../concepts/deprecation/en.md): *officially warning developers that a feature will be removed in a future update; marking old code as discouraged from use while keeping it working for now* — The practice of marking a software feature, API, or package as obsolete and discouraged from use, signaling that it will be removed in a future release.
- [**Design pattern**](../../concepts/design-pattern/en.md): *a reusable template or battle-tested solution to a commonly occurring coding problem; a proven blueprint for structuring software components to solve standard architectural challenges* — A named, proven way of structuring code that solves a design problem developers meet again and again, such as creating objects or reacting to changes.
- [**Distributed tracing**](../../concepts/distributed-tracing/en.md): *following a single user request as it travels across dozens of microservices to pinpoint where delays occur; a map showing the exact path and timing of an operation through connected servers* — A monitoring method that tracks the lifecycle of an execution request as it travels across multiple networked services and processes.
- [**Domain Name System (DNS)**](../../concepts/dns/en.md): *the internet phonebook that translates human-friendly website names like example.com into computer IP addresses; the directory service connecting domain names to web server numbers* — The hierarchical, decentralized naming system that translates human-readable domain names into numerical IP addresses for network routing.
- [**Docker**](../../concepts/docker/en.md): *the most popular software tool for building, running, and managing containers; the platform that popularised container packaging for modern software development* — An open commercial platform providing tooling to build, share, package, and execute application containers using host operating system virtualization.
- [**Edge case**](../../concepts/edge-case/en.md): *an unusual or extreme scenario that occurs only at the outer limits of operating parameters; a rare condition or extreme input that software must handle without failing* — A problem or operational situation that occurs only at extreme minimum or maximum operating parameters, testing the boundaries of system resilience.
- [**Embedding**](../../concepts/embedding/en.md): *turning words into a list of numbers so a computer can compare meanings; numbers that place similar ideas close together* — A list of numbers learned by a model to represent an item such as a word or a document, so that similar items end up close together.
- [**Encryption**](../../concepts/encryption/en.md): *scrambling secret information into unreadable code that only someone with the correct key can unlock; locking confidential data with a digital key so eavesdroppers see only scrambled nonsense* — The cryptographic process of encoding plaintext into ciphertext so that only authorized parties with the matching decryption key can read it.
- [**End-to-end test**](../../concepts/end-to-end-test/en.md): *simulating a complete real user journey through the entire application from start to finish; testing an entire system including frontend, backend, database, and third-party integrations together* — A comprehensive testing methodology that validates the flow of an application from the user interface down through all underlying backend services and databases.
- [**Environment variable**](../../concepts/environment-variable/en.md): *a dynamic key-value setting stored outside software code to configure how it behaves in different environments; a configuration variable provided by the operating system to running programs* — A dynamic key-value pair stored in the operating system environment that configures program behavior without altering application source code.
- [**Epoch (AI)**](../../concepts/epoch-ml/en.md): *one complete pass of an entire training dataset through an AI model; a full cycle of training where every single example has been seen once* — One complete training cycle during which the learning algorithm processes every sample in the training dataset exactly once.
- [**Extract, Transform, Load (ETL)**](../../concepts/etl/en.md): *pulling data from various places, cleaning it up, and saving it into a central analytics database; the three-step data pipeline that prepares raw business numbers for dashboards and reports* — A data integration process that extracts data from multiple sources, transforms it to meet analytical requirements, and loads it into a destination store.
- [**Feature flag**](../../concepts/feature-flag/en.md): *a software switch that turns a feature on or off without deploying new code; a configuration toggle allowing gradual rollout of features to specific users* — A software engineering technique that enables or disables functionality remotely at runtime through configuration without altering and redeploying source code.
- [**Few-shot prompting**](../../concepts/few-shot-prompting/en.md): *showing the AI a few examples before asking; teaching by examples inside the question* — A prompting technique that includes a few worked examples of the task so the model follows the same pattern.
- [**Fine-tuning**](../../concepts/fine-tuning/en.md): *training an existing AI a bit more on your own examples; teaching a ready-made model a specialised job* — Further training of a pre-trained model on a smaller task-specific dataset so it performs better on that task or style.
- [**Function calling**](../../concepts/function-calling/en.md): *letting the AI press buttons in other apps; the AI asking your code to fetch data or run an action* — A model capability to reply with a structured request to call a tool the developer defined; the app runs it and returns the result.
- [**Branch (Git)**](../../concepts/git-branch/en.md): *an independent line of work in a repository allowing safe experimentation; a movable pointer pointing to the latest commit in an isolated development path* — A lightweight movable reference pointing to a specific commit within a Git repository that represents an independent timeline of development.
- [**Commit (Git)**](../../concepts/git-commit/en.md): *a saved snapshot recording the exact state of project files with an explanatory note; a permanent record in the repository history describing what was changed and who changed it* — An immutable snapshot of staged changes recorded into Git repository history, associated with author metadata, timestamp, parent hashes, and a descriptive log message.
- [**Rebase**](../../concepts/git-rebase/en.md): *moving your branch commits so they sit on top of the newest commit of another branch; rewriting Git history to produce a neat, linear sequence of project changes* — A Git command that moves or reapplies a sequence of commits from one branch on top of a new base tip, creating a linear history.
- [**Graphics Processing Unit (GPU)**](../../concepts/gpu/en.md): *high-performance computer chips designed to handle massive parallel math for AI; the dedicated hardware processors that accelerate neural network training and inference* — A specialized electronic processor optimized for high-throughput parallel execution of mathematical matrix operations essential for deep learning.
- [**Graphics Processing Unit (GPU)**](../../concepts/gpu/en.md): *high-performance computer chips designed to handle massive parallel math for AI; the dedicated hardware processors that accelerate neural network training and inference* — A specialized electronic processor optimized for high-throughput parallel execution of mathematical matrix operations essential for deep learning.
- [**Gradient descent**](../../concepts/gradient-descent/en.md): *the core optimization math that guides AI models toward lower error; taking small steps down a mathematical slope to find the best model weights* — An iterative optimization algorithm that updates model parameters in the opposite direction of the loss function gradient to minimize prediction error.
- [**GraphQL**](../../concepts/graphql/en.md): *an API tool that lets client apps request only the exact data fields they need; a single query language for frontends to fetch custom data shapes in one go* — An open query language and runtime for APIs that allows clients to request exact data shapes and consolidate multiple resources in one request.
- [**Grounding (AI)**](../../concepts/grounding-ai/en.md): *anchoring an AI's answers in verified factual documents to prevent made-up facts; ensuring a model's statements are directly tied to real, verifiable source citations* — The process of constraining a model's outputs to factual, verifiable evidence retrieved from trusted external data sources.
- [**Guardrail (AI)**](../../concepts/guardrail/en.md): *safety filters around a chatbot; rules that block harmful or off-topic AI answers* — A control around a model’s inputs or outputs that detects and blocks unsafe, off-policy or off-topic content.
- [**Hallucination (AI)**](../../concepts/hallucination/en.md): *when the AI confidently makes things up; a made-up fact or fake citation from a chatbot* — Output from a generative model that sounds plausible but is false or unsupported, presented as if it were fact.
- [**Hashing (Cryptography)**](../../concepts/hashing/en.md): *turning any piece of text into a unique fixed-length fingerprint that cannot be reversed; a one-way mathematical transformation commonly used to store passwords safely* — A cryptographic process that transforms arbitrary input data into a fixed-length string of characters using an irreversible one-way mathematical algorithm.
- [**Hotfix**](../../concepts/hotfix/en.md): *an emergency patch deployed straight to production to repair a critical defect; a fast, targeted fix addressing an urgent live outage outside the normal release cycle* — An expedited software patch created and deployed directly to production systems outside standard release cycles to resolve critical defects or security flaws.
- [**HTTP status code**](../../concepts/http-status-code/en.md): *three-digit numbers that explain whether a web request succeeded or what went wrong; the server’s quick status signal like 404 not found or 200 ok* — A standardized three-digit integer returned by a server indicating the outcome of a client’s HTTP request.
- [**Hyperparameter**](../../concepts/hyperparameter/en.md): *configuration settings chosen by engineers before starting AI training; the external dials and knobs controlling how an algorithm learns* — An external configuration setting specified prior to training that governs how the model architecture is structured and optimized.
- [**Idempotency**](../../concepts/idempotency/en.md): *the property where executing an action multiple times produces the exact same result as doing it once; safely retrying an operation without causing duplicate charges or unintended side effects* — A property of an operation whereby running it again with identical inputs leaves the system in the same state as running it once.
- [**Image classification**](../../concepts/image-classification/en.md): *an AI vision task that assigns a single overall label to an entire picture; identifying what main object or category is shown in a photo* — A computer vision task in which an algorithm analyzes an entire image and assigns it one or more discrete categorical labels from a predefined taxonomy.
- [**Incident (IT)**](../../concepts/incident/en.md): *an unplanned event that breaks software or degrades service quality for users; a sudden technical emergency that requires immediate engineering intervention* — An unplanned interruption, degradation, or disruption of an IT service that impairs business operations or user experience.
- [**Inference (AI)**](../../concepts/inference/en.md): *running a trained AI model to get live answers or classifications; using an existing model on new inputs without changing its weights* — The operational stage where a trained model processes live inputs to generate predictions, decisions, or outputs without updating its parameters.
- [**Infrastructure as code (IaC)**](../../concepts/infrastructure-as-code/en.md): *setting up servers, databases, and networks using code files rather than clicking around in cloud consoles; managing computer infrastructure through version-controlled text files that can be reviewed and tested* — The practice of managing, provisioning, and configuring IT infrastructure through machine-readable definition files rather than manual procedures.
- [**Integration test**](../../concepts/integration-test/en.md): *checking whether different software parts work properly when joined together; testing real interactions between code, databases, and connected services* — An automated test that verifies whether multiple software components, modules, or external systems cooperate and exchange data correctly.
- [**Jailbreak (AI)**](../../concepts/jailbreak/en.md): *tricking a chatbot into breaking its own safety rules; prompts that make the AI say what it should refuse* — A prompt designed to make a model ignore its safety guidelines and produce content it is meant to refuse.
- [**JSON**](../../concepts/json/en.md): *a universal text format used to send data between websites and servers; human-readable curly-brace text organizing names and values in software* — A lightweight, text-based data interchange format built on key-value pairs and ordered lists that is easy for humans to read and machines to parse.
- [**JSON Web Token (JWT)**](../../concepts/jwt/en.md): *a compact digitally signed text token used to prove your identity across web requests; a three-part encrypted-looking string that carries user login claims inside an http header* — A self-contained web token format conveying verifiable identity assertions through encoded header, payload, and digital signature segments.
- [**Distillation (AI)**](../../concepts/knowledge-distillation/en.md): *training a smaller, faster AI model to mimic the knowledge of a huge model; transferring wisdom from an expert AI teacher into a compact student model* — A model compression technique where a compact student model is trained on output probability distributions generated by a larger, pre-trained teacher model.
- [**Kubernetes**](../../concepts/kubernetes/en.md): *an orchestration platform that automatically deploys, scales, and heals containers across clusters of machines; the industry standard control system for managing container fleets in production* — An open-source container orchestration system for automating deployment, scaling, management, and self-healing of containerized applications.
- [**Pod (Kubernetes)**](../../concepts/kubernetes-pod/en.md): *the smallest deployable unit in Kubernetes, containing one or more tightly linked containers; a shared wrapper that gives grouped containers the same IP address and storage volumes* — The smallest deployable computing unit in Kubernetes, encapsulating one or more tightly coupled containers sharing network and storage resources.
- [**Latency (Network)**](../../concepts/latency/en.md): *the time delay between sending a request and receiving the answer back over a network; how long you wait for a website or server to respond after clicking* — The time delay incurred for data to travel across a network from its source to its destination and return.
- [**Principle of least privilege**](../../concepts/least-privilege/en.md): *giving users and apps only the exact minimum permissions required to perform their daily job; the security rule that people should never have admin access unless strictly necessary* — A core cybersecurity principle dictating that users, accounts, and processes are granted only the minimum permissions necessary to perform their assigned functions.
- [**Linter**](../../concepts/linter/en.md): *a tool that scans your code to find style errors, suspicious patterns, and potential bugs; an automated spell-checker for programming languages* — A static code analysis tool that inspects source code for programmatic errors, stylistic inconsistencies, security antipatterns, and non-standard syntax before runtime.
- [**Large Language Model**](../../concepts/llm/en.md): *an AI that writes text by guessing the next word; the kind of chatbot brain behind ChatGPT, Gemini or Claude* — A very large neural network trained on huge amounts of text that reads and writes language by predicting the next token.
- [**Eval (AI)**](../../concepts/llm-eval/en.md): *an automated or human test process used to score an AI model's answers; measuring how well a language model performs on real-world business tasks* — A systematic evaluation methodology using automated judges, deterministic checks, or human grading to measure language model quality, safety, and correctness.
- [**Load balancer**](../../concepts/load-balancer/en.md): *a traffic cop that distributes incoming website visitors evenly across multiple backend servers; a device or service preventing any single server from becoming overwhelmed by web requests* — A networking component that distributes incoming application or network traffic across a pool of backend destination servers.
- [**Log (Software)**](../../concepts/log/en.md): *a timestamped text record written by software to explain what it just did; the running diary of events, errors, and actions that an application keeps* — A timestamped, discrete record of an event or state change emitted by a running computer program or system service.
- [**Low-Rank Adaptation**](../../concepts/lora/en.md): *a cheap way to fine-tune by training only a small add-on; small adapter files that teach a big model a new skill* — A parameter-efficient fine-tuning method that freezes the original weights and trains small low-rank matrices that represent the weight update.
- [**Loss function**](../../concepts/loss-function/en.md): *the mathematical scoring system that measures how wrong an AI model's answers are; a formula calculating the penalty when predictions deviate from true outcomes* — A mathematical function quantifying the discrepancy between a model's predicted outputs and true ground-truth targets.
- [**Machine learning**](../../concepts/machine-learning/en.md): *software that learns rules from examples instead of explicit programming; computer systems improving their accuracy automatically through experience* — A branch of artificial intelligence where computer systems detect underlying patterns in data to improve task performance without static rule engines.
- [**Model Context Protocol**](../../concepts/mcp/en.md): *a standard plug that lets AI apps connect to tools and data; one common way for chatbots to talk to other software* — An open protocol that standardises how AI applications connect to external tools, data sources and workflows through MCP servers.
- [**Merge conflict**](../../concepts/merge-conflict/en.md): *a dispute where two branches edited the same lines of a file and Git cannot choose automatically; a clash in version control that requires manual human intervention to reconcile differing changes* — A state in version control that arises when competing changes are made to the same lines of code or when one branch modifies a file that another branch deletes, preventing automatic merging.
- [**Message queue**](../../concepts/message-queue/en.md): *a digital waiting line where servers leave jobs for worker programs to process one by one; a buffer holding background tasks so web servers stay responsive during heavy traffic* — An asynchronous communication component that stores messages in sequence until receiving consumer services retrieve and process them.
- [**Metric (Monitoring)**](../../concepts/metric-monitoring/en.md): *a numerical measurement tracked over time to see how busy or healthy a computer system is; aggregated statistics like CPU percentage, memory usage, or requests per second* — A quantifiable, aggregated numerical measurement recorded at regular time intervals to evaluate system performance and health.
- [**Multi-factor authentication (MFA)**](../../concepts/mfa/en.md): *logging in with two different proofs such as your password plus a code sent to your phone; a security checkpoint requiring a password and a fingerprint before opening an account* — An authentication security method requiring users to supply two or more distinct evidence factors before granting access to a digital system.
- [**Microservices**](../../concepts/microservices/en.md): *building software as a suite of small, independent services that communicate over a network; an architectural style where each business capability runs in its own deployable process* — An architectural style that structures an application as a collection of small, independently deployable, and loosely coupled services communicating via lightweight protocols.
- [**Model (AI)**](../../concepts/ml-model/en.md): *the trained software artifact that makes AI predictions; an algorithm packed with learned weights ready to run* — A mathematical representation trained on data that captures patterns to generate predictions, decisions, or new content.
- [**Mock (Testing)**](../../concepts/mock-object/en.md): *a simulated software stand-in used to test code without calling real external services; a fake object that checks whether expected functions were called with correct parameters* — A simulated object that mimics the behavior of a real component in controlled ways, allowing developers to verify interactions and method invocations in isolation.
- [**Parameter (AI)**](../../concepts/model-parameter/en.md): *the internal numerical values that an AI adjusts as it learns; the weights and biases inside a model that define how it responds* — An internal numerical variable within a model, such as a weight or bias, whose value is learned and updated directly from training data.
- [**Training (AI)**](../../concepts/model-training/en.md): *the computational process of teaching an AI model using data; feeding examples into an algorithm so it can adjust its internal weights* — The iterative computational process of calculating errors and adjusting model weights against training data to minimize loss.
- [**Monorepo**](../../concepts/monorepo/en.md): *storing multiple distinct projects, apps, and shared libraries inside one single repository; a unified code repository holding all the different services of an organization* — A software development approach and repository architecture where multiple separate projects, applications, and shared libraries reside within a single version control repository.
- [**Neural network**](../../concepts/neural-network/en.md): *an AI computing structure inspired by interconnected biological brain cells; layered mathematical nodes passing signals forward to identify complex patterns* — A computational architecture comprising interconnected layers of artificial nodes that pass weighted signals through non-linear activation functions.
- [**OAuth**](../../concepts/oauth/en.md): *the security system that lets you log in with Google without giving your password to third-party apps; a delegation protocol granting limited permissions to an app on your behalf* — An open standard authorization framework that enables third-party applications to obtain limited access to protected user resources without sharing user passwords.
- [**Object detection**](../../concepts/object-detection/en.md): *an AI vision task that identifies multiple items in a photo and draws bounding boxes around them; finding where objects are located in an image and labeling each one* — A computer vision technique that simultaneously identifies the semantic class and spatial coordinates of multiple individual objects within an image.
- [**Observability**](../../concepts/observability/en.md): *understanding what is happening inside a complex system just by looking at its outputs and data; the ability to diagnose unknown software problems using telemetry data* — The extent to which the internal states and execution paths of complex software systems can be inferred solely from their external telemetry outputs.
- [**On-call**](../../concepts/on-call/en.md): *being available outside normal hours to respond immediately if production software breaks; the scheduled shift where an engineer carries the alert pager and fixes critical outages* — An operational duty rotation where designated engineers remain available to receive alerts and remediate critical production incidents outside or during standard working hours.
- [**Object-Relational Mapping (ORM)**](../../concepts/orm/en.md): *a programming bridge that lets developers query database tables using normal code objects; software that translates programming objects into SQL database rows automatically* — A software technique that bridges object-oriented code and relational databases by mapping database tables to programming language classes.
- [**Overfitting**](../../concepts/overfitting/en.md): *when an AI memorizes practice data so closely that it fails on fresh inputs; an AI model scoring near perfect in practice tests but failing real exams* — A modeling pathology where an algorithm learns idiosyncratic noise in training samples, severely impairing its ability to generalize to unseen data.
- [**Pagination**](../../concepts/pagination/en.md): *dividing huge lists of data into smaller chunks across multiple pages; loading search results ten or twenty items at a time instead of everything at once* — A design technique that breaks large data sets into discrete subsets or pages to manage bandwidth and system performance.
