# Termbridge Master Index (ja)

- [**A/B testing**](../../concepts/ab-testing/en.md) [product/metrics, media/digital-marketing/metrics-analytics]: *splitting users between two variants of a screen or feature to see which one performs better, controlled trial where real users are randomly split to measure which design drives higher conversions* — A randomized experimental method where two variants of a digital experience are shown to visitors simultaneously to determine which drives superior outcomes.
- [**Acceptance criteria**](../../concepts/acceptance-criteria/en.md) [product/agile-scrum]: *specific checklist of conditions that a user story must satisfy before being marked complete, unambiguous rules showing developers and testers exactly how a feature should behave* — A predefined set of conditions, behaviors, and boundary checks that a specific user story must satisfy to be accepted.
- [**Agent (AI)**](../../concepts/ai-agent/en.md) [it/ai-ml/llm-agents]: *an AI system that plans steps and uses tools to achieve goals independently, a software assistant that observes its environment, takes actions, and completes tasks* — An autonomous AI system that reasons over objectives, breaks goals into sequential steps, and interacts with tools and environments to complete tasks.
- [**Benchmark (AI)**](../../concepts/ai-benchmark/en.md) [it/ai-ml/mlops]: *standardized test suites used to measure AI model accuracy and hardware speed, common evaluation exams allowing different AI systems to be fairly compared* — A standardized test suite and measurement protocol used to evaluate and compare the accuracy, throughput, latency, or energy efficiency of models and hardware.
- [**Application Programming Interface (API)**](../../concepts/api/en.md) [it/web/api, it/software-engineering/programming-concepts]: *a defined bridge that allows two software systems to talk to each other, a digital waiter taking requests from one application to another* — A set of defined rules, protocols, and endpoints enabling different software applications to communicate and exchange data.
- [**Endpoint (API)**](../../concepts/api-endpoint/en.md) [it/web/api]: *the specific web address where an app sends requests to get certain information, a digital front door where external software asks a server to do something* — A dedicated network address and URL path exposed by an API where clients access a specific service or resource.
- [**Attention mechanism**](../../concepts/attention-mechanism/en.md) [it/ai-ml/foundations]: *an AI technique that weighs which input words matter most at each step, the computational method letting models focus dynamically on relevant context* — A mathematical algorithm allowing neural models to calculate dynamic relevance weights between all tokens within an input sequence.
- [**Autoscaling**](../../concepts/autoscaling/en.md) [it/infrastructure/cloud]: *automatically adding more servers when traffic spikes and removing them when things quiet down to save money, the system capability that expands or shrinks computing power based on real-time demand* — A cloud mechanism that automatically adjusts the number of active computing resources up or down based on real-time demand metrics.
- [**Batch size**](../../concepts/batch-size/en.md) [it/ai-ml/foundations]: *the number of training examples processed together in one forward and backward step, how many data samples an AI looks at before updating its internal weights* — The number of training samples processed simultaneously in a single iteration before the model parameters are updated.
- [**Blue-green deployment**](../../concepts/blue-green-deployment/en.md) [it/devops/ci-cd]: *running two identical environments side by side and switching user traffic instantly to the new one, a release technique that eliminates downtime by preparing updates in a cloned backup environment* — A deployment strategy that provisions two identical production environments (Blue and Green), shifting all traffic from the active to the idle environment upon validation.
- [**Breaking change**](../../concepts/breaking-change/en.md) [it/software-engineering/practices]: *a modification in software or an API that breaks existing programs depending on it, an update that requires downstream developers to rewrite parts of their code to keep working* — A modification in a software interface, dependency, or system component that breaks backward compatibility and necessitates code adjustments in dependent systems.
- [**Burndown chart**](../../concepts/burndown-chart/en.md) [product/delivery-planning]: *visual graph showing remaining work decreasing day by day throughout a sprint, progress tracking chart comparing actual remaining effort against an ideal completion slope* — A graphical representation of work left to do versus time, utilized by agile squads to forecast sprint completion trajectories.
- [**Cache (Software)**](../../concepts/cache/en.md) [it/web/backend]: *a fast temporary storage area saving frequent answers so the computer skips slow re-calculations, keeping copies of popular web pages in memory so users don't wait for slow database queries* — A high-speed data storage layer that stores a subset of transient data so future requests are served faster than accessing primary storage.
- [**Canary release**](../../concepts/canary-release/en.md) [it/devops/ci-cd]: *testing a new software version on a tiny percentage of real users before releasing it to everyone, a gradual rollout technique that exposes early bugs safely without risking the entire user base* — A deployment technique that exposes a new software release to a small fraction of production traffic to validate behavior before broader rollout.
- [**Content Delivery Network (CDN)**](../../concepts/cdn/en.md) [it/infrastructure/networking]: *a worldwide network of caching servers that delivers web pages and images quickly from locations near the user, a distributed cache that speeds up websites by serving files from nearby edge servers* — A geographically distributed network of proxy servers that caches and delivers web content to users with low latency and high availability.
- [**Chain-of-thought prompting**](../../concepts/chain-of-thought/en.md) [it/ai-ml/llm-agents]: *asking the AI to think step by step, making the AI show its working before the answer* — A prompting technique that asks a model to reason through intermediate steps before it gives the final answer.
- [**Churn rate**](../../concepts/churn-rate/en.md) [product/metrics]: *percentage of customers who stop using or paying for a service during a given time period, rate at which subscribers cancel memberships or abandon an application* — The share of paying users who stop, by cancelling or not renewing, during a given period.
- [**CI/CD**](../../concepts/ci-cd/en.md) [it/devops/ci-cd]: *automatically building, testing, and shipping code changes whenever engineers push work, the automated pipeline that moves software from development to live production servers* — A modern engineering methodology uniting frequent source integration with automated regression testing and reliable application deployment.
- [**Pipeline (CI/CD)**](../../concepts/ci-pipeline/en.md) [it/devops/ci-cd]: *the step-by-step automated workflow that builds, tests, and packages code changes, the scripted sequence that takes software from a commit to a deployable artifact* — A defined sequential series of automated execution steps that compiles, tests, and packages application updates.
- [**Code review**](../../concepts/code-review/en.md) [it/software-engineering/practices]: *having teammate developers examine your code changes before merging, a peer inspection of source code to catch bugs and uphold standards* — A collaborative peer-review practice where software engineers systematically examine proposed code changes to identify defects, enforce architectural standards, and share knowledge.
- [**Compound Interest**](../../concepts/compound-interest/en.md) [finance/personal-finance/saving, finance/investing/portfolio-risk]: *interest on interest, money snowballing because earnings get added back to the pile* — Interest calculated on both the initial principal and the accumulated interest from previous periods.
- [**Image (Container)**](../../concepts/container-image/en.md) [it/devops/containers]: *the static template or blueprint used to create and run containers, a frozen snapshot of software files, system libraries, and startup commands* — An immutable, read-only package containing application binaries, libraries, configuration files, and metadata required to launch a container.
- [**Context engineering**](../../concepts/context-engineering/en.md) [it/ai-ml/llm-agents]: *the practice of carefully designing and managing everything fed into an AI's context window, organizing tokens, instructions, tools, and history to maximize AI accuracy and reduce cost* — The disciplined practice of curating, structuring, compressing, and caching the information loaded into a model's context window to optimize performance and efficiency.
- [**Context window**](../../concepts/context-window/en.md) [it/ai-ml/llm-agents]: *how much text the AI can keep in mind at once, the AI’s working memory limit* — The maximum amount of text, counted in tokens, that a model considers in one request, covering the prompt, the conversation so far and its reply.
- [**Cookie**](../../concepts/cookie/en.md) [it/web/frontend, media/digital-marketing/paid-ads]: *small browser file websites save to remember your login, web tracker banner you click accept on* — A small piece of data stored on the user's browser by websites to retain state and track browsing activity.
- [**Cross-Origin Resource Sharing (CORS)**](../../concepts/cors/en.md) [it/web/api, it/security/vulnerabilities]: *a browser security check deciding if one website can fetch data from another domain, the rules preventing malicious websites from secretly querying your banking API* — A browser security protocol using special HTTP headers that lets an API grant specific foreign websites permission to fetch its content.
- [**Cross-site request forgery (CSRF)**](../../concepts/csrf/en.md) [it/security/vulnerabilities]: *an attack that tricks your browser into making unwanted money transfers on sites where you are logged in, clicking a trap link on an external page that secretly submits a form to change your account email* — An attack that tricks an authenticated web browser into sending unauthorized commands to a vulnerable web application without the user’s consent.
- [**Customer lifetime value (CLV)**](../../concepts/customer-lifetime-value/en.md) [product/metrics]: *total amount of money a business expects to earn from a customer throughout their entire relationship, projected net profit or revenue generated by a single user account over its lifespan* — The projected total revenue or profit that a business anticipates earning from a single customer throughout the duration of their relationship.
- [**Common Vulnerabilities and Exposures (CVE)**](../../concepts/cve/en.md) [it/security/vulnerabilities]: *the standardized global dictionary of publicly recognized cybersecurity flaws and software bugs, an official tracking code like CVE-2021-44228 identifying a specific security flaw* — A publicly available list of standardized identifiers for cybersecurity vulnerabilities and exposures.
- [**Daily active users (DAU)**](../../concepts/daily-active-users/en.md) [product/metrics]: *count of unique people who open and interact with an application in a single day, vital metric tracking daily user volume and ongoing product engagement* — The total count of unique individuals who initiate a meaningful interaction with a software application within a 24-hour day.
- [**Daily Scrum**](../../concepts/daily-scrum/en.md) [product/agile-scrum]: *quick fifteen-minute daily morning meeting for developers to sync on sprint progress, brief stand-up check-in where teammates share achievements, plans, and immediate blockers* — A 15-minute daily inspect-and-adapt event for developers to synchronize activities and plan the next 24 hours of work.
- [**Data lake**](../../concepts/data-lake/en.md) [it/data/data-engineering]: *a huge digital reservoir where companies store raw data in any format until needed, a flexible storage pool holding audio, text, images, and logs without forcing strict table structures* — A scalable storage repository designed to retain massive volumes of raw multi-format information without requiring an upfront database schema.
- [**Data pipeline**](../../concepts/data-pipeline/en.md) [it/data/data-engineering]: *an automated series of steps moving information from where it is created to where it is used, software plumbing that pumps live data from user clicks into analytics systems* — An automated sequence of processes that ingests, processes, and transfers raw data from source systems to destination storage.
- [**Data warehouse**](../../concepts/data-warehouse/en.md) [it/data/data-engineering]: *a central database designed specifically for business analysis and fast executive reporting, a giant organized filing room where companies store cleaned historical business records* — A centralized, relational repository that aggregates structured historical data from across an organization to power business intelligence and reporting.
- [**Index (Database)**](../../concepts/database-index/en.md) [it/data/database]: *a sorted lookup helper that lets the database find specific rows in milliseconds instead of scanning the whole disk, an alphabetical index at the back of a book pointing directly to table rows* — A specialized data structure associated with a database table that accelerates record retrieval at the expense of extra storage and slower writes.
- [**Migration (Database)**](../../concepts/database-migration/en.md) [it/data/database]: *a version-controlled script that safely updates database table layouts as software evolves, a step-by-step code file for adding new columns or tables to live databases* — A version-controlled set of programmatic scripts that safely alter database schemas over time without losing existing data.
- [**Replication (Database)**](../../concepts/database-replication/en.md) [it/data/database]: *copying database records automatically to backup servers so the system survives hardware failures, syncing data across multiple database copies so heavy user reads don't slow down writes* — The continuous electronic copying of data from one database server to one or more replica servers to ensure high availability and read scalability.
- [**Schema (Database)**](../../concepts/database-schema/en.md) [it/data/database]: *the overall architectural blueprint defining the tables, columns, and rules in a database, the formal structural layout describing what kinds of data a database is allowed to hold* — The formal structural blueprint of a database that defines tables, fields, data types, relationships, and integrity constraints.
- [**Transaction (Database)**](../../concepts/database-transaction/en.md) [it/data/database]: *an all-or-nothing group of database operations that either completely succeeds or leaves data untouched, a safe execution wrapper ensuring money transfers debit one account and credit another atomically* — A sequence of database operations executed as a single, atomic unit of work satisfying ACID properties.
- [**Dataset**](../../concepts/dataset/en.md) [it/ai-ml/foundations]: *a structured collection of examples used to teach or test AI, the organized data gathered together for machine learning experiments* — A structured collection of data records, features, and targets partitioned to train, validate, and benchmark algorithms.
- [**Deep learning**](../../concepts/deep-learning/en.md) [it/ai-ml/foundations]: *machine learning powered by deep neural networks with many hidden layers, advanced AI techniques that automatically learn rich representations from raw data* — A specialized subset of machine learning utilizing multi-layered neural networks to extract hierarchical feature representations directly from complex data.
- [**Definition of Done (DoD)**](../../concepts/definition-of-done/en.md) [product/agile-scrum]: *shared quality checklist that every piece of work must meet before being considered finished, formal agreement covering code reviews, automated tests, documentation, and deployment steps* — A formal commitment detailing the technical and quality standards that every product increment must satisfy to be release-ready.
- [**Deprecation (Software)**](../../concepts/deprecation/en.md) [it/software-engineering/practices]: *officially warning developers that a feature will be removed in a future update, marking old code as discouraged from use while keeping it working for now* — The practice of marking a software feature, API, or package as obsolete and discouraged from use, signaling that it will be removed in a future release.
- [**Design pattern**](../../concepts/design-pattern/en.md) [it/software-engineering/architecture]: *a reusable template or battle-tested solution to a commonly occurring coding problem, a proven blueprint for structuring software components to solve standard architectural challenges* — A named, proven way of structuring code that solves a design problem developers meet again and again, such as creating objects or reacting to changes.
- [**Distributed tracing**](../../concepts/distributed-tracing/en.md) [it/devops/observability]: *following a single user request as it travels across dozens of microservices to pinpoint where delays occur, a map showing the exact path and timing of an operation through connected servers* — A monitoring method that tracks the lifecycle of an execution request as it travels across multiple networked services and processes.
- [**Domain Name System (DNS)**](../../concepts/dns/en.md) [it/infrastructure/networking]: *the internet phonebook that translates human-friendly website names like example.com into computer IP addresses, the directory service connecting domain names to web server numbers* — The hierarchical, decentralized naming system that translates human-readable domain names into numerical IP addresses for network routing.
- [**Docker**](../../concepts/docker/en.md) [it/devops/containers]: *the most popular software tool for building, running, and managing containers, the platform that popularised container packaging for modern software development* — An open commercial platform providing tooling to build, share, package, and execute application containers using host operating system virtualization.
- [**Edge case**](../../concepts/edge-case/en.md) [it/software-engineering/testing]: *an unusual or extreme scenario that occurs only at the outer limits of operating parameters, a rare condition or extreme input that software must handle without failing* — A problem or operational situation that occurs only at extreme minimum or maximum operating parameters, testing the boundaries of system resilience.
- [**Embedding**](../../concepts/embedding/en.md) [it/ai-ml/nlp]: *turning words into a list of numbers so a computer can compare meanings, numbers that place similar ideas close together* — A list of numbers learned by a model to represent an item such as a word or a document, so that similar items end up close together.
- [**Encryption**](../../concepts/encryption/en.md) [it/security/cryptography]: *scrambling secret information into unreadable code that only someone with the correct key can unlock, locking confidential data with a digital key so eavesdroppers see only scrambled nonsense* — The cryptographic process of encoding plaintext into ciphertext so that only authorized parties with the matching decryption key can read it.
- [**End-to-end test**](../../concepts/end-to-end-test/en.md) [it/software-engineering/testing]: *simulating a complete real user journey through the entire application from start to finish, testing an entire system including frontend, backend, database, and third-party integrations together* — A comprehensive testing methodology that validates the flow of an application from the user interface down through all underlying backend services and databases.
- [**Environment variable**](../../concepts/environment-variable/en.md) [it/devops/ci-cd]: *a dynamic key-value setting stored outside software code to configure how it behaves in different environments, a configuration variable provided by the operating system to running programs* — A dynamic key-value pair stored in the operating system environment that configures program behavior without altering application source code.
- [**Epic (Agile)**](../../concepts/epic-agile/en.md) [product/agile-scrum]: *large body of work that spans multiple sprints and is split into several user stories, major product initiative or feature theme organized across a longer development timeframe* — A substantial strategic initiative in agile software delivery that encompasses a collection of related user stories delivered over several sprints.
- [**Epoch (AI)**](../../concepts/epoch-ml/en.md) [it/ai-ml/foundations]: *one complete pass of an entire training dataset through an AI model, a full cycle of training where every single example has been seen once* — One complete training cycle during which the learning algorithm processes every sample in the training dataset exactly once.

- [**Function calling**](../../concepts/function-calling/en.md) [it/ai-ml/llm-agents]: *letting the AI press buttons in other apps, the AI asking your code to fetch data or run an action* — A model capability to reply with a structured request to call a tool the developer defined; the app runs it and returns the result.

- [**Unit test**](../../concepts/unit-test/en.md) [it/software-engineering/testing]: *an automated check testing the smallest single piece of code in isolation, verifying that an individual function returns the correct answer for given inputs* — An automated test that isolates and verifies the behavioral correctness of the smallest testable component or function of an application.
- [**Uptime**](../../concepts/uptime/en.md) [it/devops/sre-operations]: *the percentage of time a computer system or website is running and ready for users, how long a service stays available without crashing or going offline* — The proportion or duration of time that a computer system, network, or application remains fully functional and accessible to users.
- [**User story**](../../concepts/user-story/en.md) [product/agile-scrum]: *short informal description of a software feature framed from the perspective of an end user, practical work item explaining who needs a capability, what they need, and why it provides value* — A concise, non-technical explanation of a software requirement capturing user intent, desired functionality, and business value.
- [**Vector database**](../../concepts/vector-database/en.md) [it/ai-ml/nlp]: *a database that finds things by similar meaning, storage that searches by how close lists of numbers are* — A database built to store embedding vectors and quickly return the ones most similar to a query vector.
- [**Velocity (Agile)**](../../concepts/velocity-agile/en.md) [product/agile-scrum]: *average amount of work a development team delivers during a single sprint, historical metric measuring how many story points a squad completes per iteration* — A planning metric tracking the average volume of story points or backlog items completed by a team per sprint.
- [**Virtual machine (VM)**](../../concepts/virtual-machine/en.md) [it/infrastructure/cloud]: *a software simulation of an entire physical computer running its own complete operating system, a virtual computer created inside a powerful server that behaves just like a physical machine* — A software emulation of a physical computer system that executes applications within a dedicated, isolated guest operating system managed by a hypervisor.
- [**Session (Web)**](../../concepts/web-session/en.md) [it/web/backend]: *the server-side record remembering who you are while you click around a website, the active conversation state linking multiple web page clicks to one logged-in user* — A server-side state mechanism that tracks an individual user’s interactions and identity across multiple stateless HTTP requests.
- [**Webhook**](../../concepts/webhook/en.md) [it/web/api]: *an automatic notification sent between servers as soon as something happens, a reverse phone call where a payment provider rings your app to say money arrived* — An automated HTTP POST callback triggered by an origin system to deliver real-time event payloads to external receiver endpoints.
- [**Cross-site scripting (XSS)**](../../concepts/xss/en.md) [it/security/vulnerabilities]: *a vulnerability where attackers inject malicious javascript into a website to hijack visitor browsers, sneaking rogue code into public comment sections so readers' login cookies get stolen* — A web application flaw permitting attackers to embed rogue executable scripts into viewed pages, running unauthorized actions inside visitor browsers.
- [**Zero trust**](../../concepts/zero-trust/en.md) [it/security/authentication]: *a security model that never assumes any user or device is safe, even inside the office network, the principle of verifying identity and device health for every single digital request* — A cybersecurity framework requiring continuous verification of every user, device, and network transaction, operating under the assumption that breaches are already present.
