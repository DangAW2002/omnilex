# Termbridge Index: Internet of Things (ja)

- [**Actuator**](../../concepts/actuator/en.md): *mechanism that converts electrical control commands into physical motion; component that moves or controls a physical mechanism in response to a signal* — An output device that converts electrical control signals into physical movement, force, or mechanical displacement.
- [**Bluetooth Low Energy (BLE)**](../../concepts/ble/en.md): *short range wireless personal area network technology designed for minimal battery drain; power efficient radio specification for exchanging sensor data with nearby devices* — A power-optimized wireless personal area network technology designed for short-range communication with minimal electrical energy consumption.
- [**Constrained Application Protocol (CoAP)**](../../concepts/coap/en.md): *web transfer protocol tailored for constrained nodes and low bandwidth networks using udp; lightweight http alternative designed to run restful requests on tiny microcontrollers* — A specialized RESTful web transfer protocol designed by the IETF for resource-constrained microcontrollers and low-power wireless networks using UDP.
- [**Device provisioning**](../../concepts/device-provisioning/en.md): *process of enrolling configuring and registering a new hardware unit into a cloud service; initial automated onboarding workflow that assigns credentials and configurations to devices* — The automated onboarding process that authenticates, registers, and configures newly deployed hardware devices into a centralized cloud management platform.
- [**Digital twin**](../../concepts/digital-twin/en.md): *virtual software counterpart of a physical asset updated with real time sensor metrics; computational model reflecting the live state behavior and lifecycle of real world machines* — A virtual representation that serves as the real-time computational counterpart of a physical object, process, or system synchronized through continuous telemetry.
- [**Edge computing**](../../concepts/edge-computing/en.md): *computing paradigm that analyzes and processes information near the data source location; decentralized framework running analytics directly on local hardware instead of remote servers* — A distributed computing paradigm that brings computational logic and data storage closer to the physical devices and sensors where information is generated.
- [**Firmware**](../../concepts/firmware/en.md): *permanent low level software programmed directly into device non volatile storage; foundational code that instructs hardware components how to communicate and operate* — Low-level software programmed directly into non-volatile memory that provides operational instructions and hardware abstraction for electronic devices.
- [**Gateway (IoT)**](../../concepts/iot-gateway/en.md): *bridge unit connecting field sensors with external cloud networks and translating protocols; physical hub that aggregates local device signals and forwards filtered payloads upstream* — A bridging hardware device or software appliance that aggregates field sensor data, translates communication protocols, and securely routes telemetry to cloud networks.
- [**IoT platform**](../../concepts/iot-platform/en.md): *cloud or server suite that manages connects and analyzes fleets of connected hardware; central software environment handling communication security and data processing for iot fleets* — A multi-layered middleware software suite that provides connectivity, fleet device management, data ingestion, and application integration for IoT deployments.
- [**LoRaWAN**](../../concepts/lorawan/en.md): *long range low power wireless networking protocol for remote sensor deployments; wide area communication standard that connects battery powered iot devices over kilometers* — A point-to-multipoint Low-Power Wide-Area Network (LPWAN) protocol designed for wireless, battery-operated devices communicating over long distances on unlicensed radio spectrum.
- [**Mesh network**](../../concepts/mesh-network/en.md): *network topology where nodes interconnect directly to dynamically relay data for each other; decentralized layout where each participant acts as a forwarding router without a single failure point* — A decentralized network topology where interconnected nodes collaborate to dynamically relay data across multiple hops without relying on a single central hub.
- [**Microcontroller (MCU)**](../../concepts/microcontroller/en.md): *compact single chip computer designed to govern dedicated hardware tasks; integrated circuit containing a processor core memory and input output peripherals* — A compact integrated circuit containing a processor core, memory, and programmable input/output peripherals designed for embedded control operations.
- [**Modbus**](../../concepts/modbus/en.md): *de facto standard industrial protocol that queries memory registers using master client polling; simple serial and tcp communication format widely implemented across manufacturing equipment* — A de facto industrial request-response communication protocol that reads and writes discrete memory coils and 16-bit numerical registers across serial and Ethernet links.
- [**MQTT**](../../concepts/mqtt/en.md): *lightweight messaging protocol using a publish subscribe broker model for iot devices; network standard for sending small data packets between sensors and servers over tcp* — A lightweight publish-subscribe network messaging protocol running over TCP, designed for constrained hardware and low-bandwidth connections.
- [**NB-IoT**](../../concepts/nb-iot/en.md): *cellular radio standard optimized for low bandwidth high density iot device deployments; licensed telecom network specification enabling deep indoor coverage for battery powered meters* — A narrowband cellular radio technology standard developed by 3GPP, designed for massive machine-type communication on licensed telecommunication frequencies.
- [**OPC UA**](../../concepts/opc-ua/en.md): *cross platform industrial communication architecture providing semantic data modeling and secure transport; machine to machine standard ensuring interoperability between manufacturing hardware across vendors* — A platform-independent, service-oriented communication architecture designed for industrial automation that provides rich semantic information modeling and built-in cryptographic security.
- [**Over-the-air update (OTA)**](../../concepts/ota-update/en.md): *remote wireless delivery of firmware and software updates to connected hardware fleets; process of patching device software over network connections without physical physical contact* — The remote wireless distribution and installation of new software or firmware updates to connected hardware without physical tethering.
- [**Programmable Logic Controller (PLC)**](../../concepts/plc/en.md): *ruggedized industrial computer built to execute deterministic automated factory workflows; hardened controller that reads field sensors and governs machinery through programmed logic* — A ruggedized industrial digital computer designed to execute deterministic, real-time control logic over manufacturing machinery and industrial processes.
- [**Predictive maintenance**](../../concepts/predictive-maintenance/en.md): *maintenance technique using sensor telemetry and analytics to forecast equipment failures before they happen; strategy that schedules machine servicing according to real time condition metrics rather than fixed calendar intervals* — A proactive asset management strategy that continuously monitors operational sensor telemetry to forecast machinery degradation and schedule servicing before mechanical failure occurs.
- [**Real-time operating system (RTOS)**](../../concepts/rtos/en.md): *operating system engineered to process events within guaranteed timing constraints; lightweight system that schedules tasks with deterministic latency for embedded hardware* — An operating system designed to execute processes with deterministic timing guarantees and minimal scheduling latency for mission-critical embedded devices.
- [**SCADA**](../../concepts/scada/en.md): *system architecture combining software and hardware to monitor and control expansive industrial facilities; supervisory control setup displaying plant telemetry graphics and handling operator commands* — An industrial control system architecture that gathers real-time telemetry from geographically dispersed field controllers, visualizes operational state, and allows supervisory commands.
- [**Sensor**](../../concepts/sensor/en.md): *electronic part that detects physical changes like temperature or motion; hardware module that converts real world signals into digital data* — An input hardware component that senses physical attributes of the environment and converts them into measurable electrical signals.
- [**Smart home**](../../concepts/smart-home/en.md): *residence equipped with connected devices that automate lighting climate and security; networked household setup where appliances communicate and can be managed remotely* — A residential environment equipped with interconnected electronic devices that automate domestic tasks, optimize utility usage, and enable centralized remote monitoring.
- [**Telemetry**](../../concepts/telemetry/en.md): *automated collection and remote transmission of sensor measurements to a monitoring station; continuous stream of operational readings emitted by field hardware across a network* — The automated process of collecting operational metrics and status measurements from remote points and transmitting them across communications channels for monitoring and analysis.
- [**Zigbee**](../../concepts/zigbee/en.md): *low power wireless mesh networking standard commonly used in home automation systems; radio protocol that routes sensor messages across interconnected household devices* — A low-power, wireless mesh networking standard built upon IEEE 802.15.4, designed for multi-device home automation and smart energy management.
